What is FortiAuthenticator?

FortiAuthenticator is Fortinet's centralized identity and access management platform. It enforces identity-driven security by verifying who is on the network and ensuring they're who they claim to be — supporting multi-factor authentication (MFA), Single Sign-On (SSO), RADIUS/TACACS+ authentication, PKI certificate management, and Fortinet Single Sign-On (FSSO). It is available as a hardware appliance, a virtual machine (perpetual or subscription), or as a fully managed SaaS service called FortiAuthenticator Cloud.

Where to start: Choose a Deployment Type below — Hardware Appliance, VM Subscription, VM Perpetual, or FortiAuthenticator Cloud. Your choice drives the entire BOM structure, so make this decision first based on the customer's infrastructure preference and CapEx/OpEx model.

Ordering process notes
Can I split a license for 3,000 users across two FortiAuthenticators with 1,500 users each?
No. User licenses are tied to their respective FortiAuthenticator unit. Each appliance or VM must have its own license set sized for its full user capacity — sharing across units is not supported.
How does HA work for VM Perpetual deployments?
Each VM node in an HA cluster requires its own base license, user upgrade licenses, and support contract. VM user licenses are stackable but support contracts are not — each node needs its own support SKU. Add the full license set again for each HA node.
Do I need additional FortiToken Mobile licenses for HA nodes?
No. FortiToken Mobile licenses replicate automatically across all HA nodes (Active/Passive or Active-Active Load Balancing). Purchase FTM licenses once for the cluster, not once per node.
Can existing VM Perpetual users move to VM Subscription?
For upgrades or transitions, request a co-term quotation through your authorized Fortinet partner. New orders use the standard SKU structure; cross-model conversions require a partner-assisted quote.

Sizing & architecture notes
How are object limits calculated inside FortiAuthenticator?
Most limits are derived from the total licensed user count. For example: User Groups = licensed users ÷ 5; FortiTokens = licensed users × 2; RADIUS/TACACS+ clients = licensed users ÷ 3; User Certificates = licensed users × 5. Size your license to the highest object count you'll need, not just the raw user count.
When should I choose the 3000F vs. 3000G for a large deployment?
Both start at 40,000 base users. The 3000F can expand to 240,000 users; the 3000G expands to 1,000,000. Choose 3000G if the customer may exceed 240,000 users or anticipates very large-scale growth.
Can VM user licenses be split between two FortiAuthenticators?
No. Each FortiAuthenticator unit has its own license set. You cannot allocate 3,000 users from one pool to two units of 1,500 each — each unit must be licensed independently for its full capacity.
