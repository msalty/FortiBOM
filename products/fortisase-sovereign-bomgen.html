What is FortiSASE Sovereign?

FortiSASE Sovereign is a private SASE enablement package for large enterprises, public-sector organizations, and service providers that want to deliver SASE from customer-controlled infrastructure instead of a public vendor-hosted PoP. Fortinet hosts the cloud orchestrator and portal; security inspection runs on FortiGate capacity; log and data residency is anchored by FortiAnalyzer.

Start here: Pick whether the security inspection FortiGates are customer-owned on-premises or consumed via FGaaS. Then size FortiGate capacity, FortiAnalyzer storage, and user licenses.

Ordering process notes
What four components are required?
Cloud orchestrator/portal, FortiGate security inspection entitlement/capacity, FortiAnalyzer log storage, and user licensing are all required.
Can Sovereign be combined with FortiSASE?
No. FortiSASE Sovereign is designed as a private deployment model, not as a hybrid extension of the public FortiSASE service.
Can FortiGate inspection be hosted by Fortinet?
Yes, the ordering guide references FGaaS as a way to consume hosted FortiGate inspection capacity while keeping FortiAnalyzer aligned to residency requirements.
