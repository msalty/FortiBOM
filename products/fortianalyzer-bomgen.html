🔍 What is FortiAnalyzer?

FortiAnalyzer is a fully integrated SecOps platform combining SIEM (Security Information and Event Management) and SOAR (Security Orchestration, Automation and Response) with a scalable data lake and built-in Generative AI. It collects and stores logs from your Fortinet devices, runs correlation rules to detect threats, and can automatically trigger responses via playbooks — all in one system.

💡
New to FortiAnalyzer? Start by choosing a Deployment Type below. If you have physical servers or rack space, use Appliance or VM. If you want Fortinet to host it for you, use FortiAnalyzer Cloud.

🏗 Architecture Patterns
🖥 Single Tier Standalone
One FortiAnalyzer unit. All features available. Simple and cost-effective. No redundancy — schedule regular backups.
Best for: SOHO and SMB where redundancy is not required.
🔄 High Availability (HA)
Purchase 2× the same model. All units must match: same model, firmware, operation mode, and GB/Days licensed. Provides real-time log synchronization. Each HA unit also needs its own FortiAI subscription.
Best for: Organizations requiring real-time redundancy. Supervisor: FAZ-1000G (high-end) or FAZ-300G (mid/low). No separate supervisor license needed — only FortiCare.
🌐 Multi-Tier: Collector + Analyzer
Collector nodes per region (log reception, archiving, forwarding). Analyzer node(s) in HA for analytics and reporting. Logs buffer at collector if WAN link drops. Collector mode needs only the lowest model (FAZ-150G or FAZ-VM-GB1).
Best for: International companies with regional offices needing centralized analytics.
🏗 FortiAnalyzer Fabric
A Fabric Supervisor provides central visibility across all member FortiAnalyzer units. Regional SOC teams retain full analyzer capability. No supervisor license required — only a valid FortiCare contract. Note: No HA on supervisor in FAZ 7.6; no config push from supervisor to members.
Best for: Multi-national customers with regional SOC teams needing both local control and central oversight.
📊 FortiAnalyzer BigData
Hadoop/Spark/Kafka architecture for massive scale. Horizontal scaling, built-in resiliency. Starting at 100,000 LPS. Contact Fortinet for sizing and pricing.
Best for: Large-scale data centers requiring extreme log ingestion, resiliency, and horizontal scaling.
